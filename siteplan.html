Local Bite Finder

WDD 231 Individual Website Project Plan

Student Name: Caden Griffin

1. Site Name

Name Selected: Local Bite Finder

Reasoning: This name was chosen because it clearly and memorably communicates the core tool of the website: helping users discover local dining spots based on their immediate cravings and preferences.

Optional Domain Availability: localbitefinder.org

2. Site Purpose

The website is designed to solve dinner and date-night indecision. The site provides a curated directory and interactive filtering tool for local restaurants. Users can select specific cuisine types (such as Mexican, American, or Italian), view star ratings (1–5 stars), check detailed restaurant info via accessible modals, and save their favorite spots using local storage.

3. Scenarios

Target audience questions that drive the functionality and content of the website:

  • "Where can I find a highly-rated Mexican restaurant nearby that I can check out for date night?"
  • "How can I save my favorite restaurant options to a personal list so I can review them later?"

4 & 5. Color Scheme

The following color palette is used throughout this site plan document and will be applied to the final website:

  • Primary Color (#D9534F - Warm Red/Coral): Used for primary headings, call-to-action buttons, and key interactive accents.
  • Secondary Color (#F0AD4E - Warm Amber/Gold): Used for star ratings, subtitles, badges, and highlights.
  • Background Color (#F9F9F9 - Off-White): Used for page body backgrounds to ensure soft, easy-to-read contrast.
  • Text Color (#333333 - Dark Charcoal): Used for paragraph text and general body content for high readability.

6. Typography

The site uses two clean Google Fonts to establish strong readability and modern styling:

  • Heading Font (Poppins): Applied to all major headings (<h1>, <h2>, <h3>) to give a modern, clean, structural feel.
  • Body Font (Inter): Applied to body text (<body>, <p>, <li>) for optimized legibility across both mobile and desktop screens.

7. Wireframes

Below is the structural layout plan for the home page in both mobile and wider desktop views:

Mobile View (320px+)

  • Header with Logo & Hamburger Menu icon
  • Hero banner: "Can't Decide What to Eat?"
  • Interactive craving filter dropdown
  • Vertical single-column list of restaurant cards (Name, Rating, Cuisine)
  • Footer with attribution and video link

Desktop View (Wide Screen)

  • Horizontal navigation bar with logo and page links
  • Large hero banner with search bar input
  • Side-by-side layout: Filter sidebar on left, 3-column grid of restaurant cards on right
  • Modal pop-up behavior on card click
  • Footer with attribution and video link
